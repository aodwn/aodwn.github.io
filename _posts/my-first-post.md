### 1. 프로젝트 목적
- GitHub Pages 및 Jekyll을 활용한 개인 포트폴리오 사이트 구축.
- Bento Grid 레이아웃 및 Glassmorphism 디자인을 적용하여 시인성 확보.
- 인프라 엔지니어로서의 기술 스택 및 프로젝트 경험 정량화.

### 2. 기술 스택 및 환경
- **플랫폼**: GitHub Pages
- **엔진**: Jekyll (Static Site Generator)
- **디자인**: HTML5, CSS3 (Grid/Flexbox), Glassmorphism UI
- **관리**: YAML 설정을 통한 사이트 전역 메타데이터 제어

### 3. 핵심 구현 사항
- **반응형 레이아웃**: 모바일, 태블릿, 데스크톱 환경에 최적화된 그리드 시스템 구현.
- **입체감(Depth)**: Multi-layered box-shadow 및 backdrop-filter를 활용한 UI 설계.
- **최적화**: Jekyll의 `layout: null` 선언을 통해 테마 간섭을 차단하고 커스텀 디자인 적용.

### 4. 현재 진행 상태 및 역량
- **교육**: SeSAC 청년취업사관학교 클라우드 데이터 인프라 과정 (2025.12 - 2026.04) 수료 중.
- **기술**: Linux 코어망 분석(Open5GS) 및 5G/LTE 시스템 운영 경험 보유.
- **자격 사항**:
    - ADsP 자격 취득 완료 (2025.09).
    - SQLD (2026.03) 및 리눅스마스터 2급 (2026.03) 응시 예정.
    - 정보처리기사 실기 (2026.04) 응시 예정.

### 5. 향후 계획
- 인프라 자동화 도구(Terraform, Ansible)를 활용한 프로젝트 상세 페이지 추가.
- 시스템 아키텍처 다이어그램 포함 및 기술 블로그 포스팅 지속.
